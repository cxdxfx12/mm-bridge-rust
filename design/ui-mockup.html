自定义绘制 vs 可用原生控件

需要自定义绘制（custom draw）：

  • 自定义标题栏与窗口控制按钮（无边框窗口时必做，含拖拽区 / 双击最大化）。
  • 连接状态灯（带 pulse 动画圆点）、状态徽标、KPI 卡光晕与趋势箭头。
  • 「手机画面」投屏画布：位图缩放、点击/滑动映射、中央错误文字、notch 装饰。
  • 等宽日志着色（按 INFO/SYS/TOOL/WARN/ERROR 分色）、表格斑马纹与悬停行。
  • 开关 Switch、进度条纹动画、Spinner（旋转）、聚焦环。
  • Toast 浮层与空状态插画（内联 SVG 线性图标）。

可直接使用原生 / 近原生控件：

  • 单行输入框、数字微调 Spinbox → 原生 text input / spin button。
  • 下拉框（数据来源 / 时间档位 / 巡检档位）→ 原生 combo box / select。
  • 复选框、单选按钮 → 原生 checkbox / radio（仅需换主题色）。
  • 标签页 Notebook → 原生 tab widget（套用激活条 + 浅底）。
  • 按钮 → 原生 button + 状态枚举样式（primary/secondary/danger/ghost/disabled/loading）。
  • 垂直/水平滚动区、分割线、菜单 → 框架原生能力。

建议：把所有 token 收进一个 Theme 结构（颜色 24 / 字号 9 / 间距 9 / 圆角 6 / 阴影 4 / 动效 3 组），控件只引用语义名。egui / slint 用 Style 覆盖；Tauri 前端可直接复用本文件 CSS 变量。

Guidelines

01布局栅格 Layout Grid

主窗口以 1440×900 为设计基准，采用 4px 基准栅格，所有间距、控件高度、圆角均为 4 的倍数（--sp-* / --h-control 34 / --r-*）。三列结构固定：左侧导航 216px、右侧手机画面 308px、中间主区自适应；标题栏 46、状态条 68、试运行条 34、底栏 58 均为固定高，剩余高度全给主区。中间主区再用 4 列 KPI + 主区「消息流水 1.35 : 实时日志 1」双栏栅格。窗口缩放时只允许中间主区伸缩，左右两列与所有栏高固定，避免手机画面被挤出屏幕（沿用现有 pack 顺序踩坑经验）。

02层级 Hierarchy

建立清晰的四层高度：① 桌面底 --bg-app → ② 导航 / 顶栏 --bg-surface-2 → ③ 卡片 / 面板 --bg-surface → ④ 浮层 Toast --bg-surface + shadow-md。层级靠「背景明度 + 1px 边框 + 柔和阴影」区分，不靠浓重投影。信息层级：标题 24/700 → 数值 30/700 等宽 → 正文 14/400 → 说明 12/400 次要色。强调色在任意一屏内只出现一个实心块（当前可点的主按钮），其余用描边/幽灵按钮，延续 gui.py「实心 vs 空心」判定可用态的原则。

03可读性 Readability

浅底深字，正文 #1C2740 对白底对比度约 13:1，次要文字 #5C6884 约 5.4:1，均达 WCAG AA。中文优先微软雅黑 / 思源黑体，行高 1.55–1.75；日志、时间戳、计数、Token、热键一律等宽，保证列对齐与数字辨识。长群名用单行省略号 + title 完整提示；表格行 hover 高亮、日志按级别着色（INFO 蓝 / SYS 灰 / TOOL 紫 / WARN 琥珀 / ERROR 红），但颜色从不作为唯一信息载体，始终配文字或图标。状态灯用圆点 + 文案双编码，照顾色觉障碍用户。

04深浅色适配建议 Dark Mode

本稿为浅色主题（与当前 IDE 一致），但所有颜色均通过语义变量引用，深色适配只需替换一组 token，不改任何控件代码：

  • 背景反转：--bg-app → #0F1626、--bg-surface → #1A2436、--bg-surface-2 → #212D42；文字相应反转为浅色（#E8EDF6 / #AEB9CE）。
  • 主色降饱和提亮：--c-primary → #6E9BFF，保证在深底上仍有 4.5:1；状态色同样改用浅色阶（如成功 #4CC38A）。
  • 深色下阴影几乎失效，层级改用 --border 提亮（rgba(255,255,255,.08)）的 1px 描边表达；聚焦环改半透明主色。
  • 浅底语义色（成功/警告/危险 *-50）在深色下改为「深色透明叠加」，文字用对应亮色，避免大面积高亮块刺眼。
  • 「手机画面」画布、KPI 光晕、日志代码底色单独给变量，深色时单独校准，不与通用 surface 共用。

05工程落地约束

图标全部为内联 SVG 线性图标（24 网格 / 1.7px / currentColor），Rust 侧可直接导出为路径数据或字体图标；禁止 emoji，状态点用纯几何绘制。所有交互态以「状态枚举」驱动样式（default / hover / active / focus / disabled / loading / error），与后端 worker 通过管道回传的运行状态（idle / running / checking / stopping）一一对应。文案保持真实功能口径，不使用占位文本；涉及「试运行 / 漏转 / 对账 / USB 未授权」等提示，颜色语义与 phone_panel.py 的错误分级保持一致。

交付边界：本文件为纯静态自包含 HTML（内联 CSS、零外链、无 JS 框架），仅新建 design/ui-mockup.html，未修改项目任何现有代码。双击即可在浏览器预览全部设计系统、主窗口、三态手机面板、组件规范与 Token 表。
